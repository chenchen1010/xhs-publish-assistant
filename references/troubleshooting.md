# 故障排查知识库（用户报错时的诊断依据）

> 内容来源：负责人的官方《配置引导》飞书文档（2026-07 版）+ 本 skill 构建时验证过的事实。诊断时以本文件为准，不要凭空猜测。

## 诊断三条铁律（先读这个）

1. **用户面对的是打包好的应用，改不了程序**——永远不要建议用户改代码、改脚本、"等修复"。
2. **程序本身是能正常跑的**（已有用户在正常使用）——不要把问题归因为"可能是程序 bug"。
3. **用户跑不起来，100% 是配置的某个环节出了问题**：没配置好、没按教程做、或漏了步骤。诊断的目标永远是定位到"配置的哪一步漏了/错了"，并给出可操作的修复步骤。

## 应用的完整链路（判断问题出在哪一段）

多维表格准备内容 → 影刀读取数据 → 唤起比特浏览器 → 自动发布到小红书

**RPA 拉取笔记的条件**：已发布未勾选，且（定时发布为空 = 立即发布，或 定时发布距当前北京时间 10 分钟以内）。
**错误信息出现在两个地方**：影刀运行日志、多维表格「发布任务提交时间」字段。

## 正确配置的完整清单（对照排查漏了哪步）

1. 装好影刀 RPA（yingdao.com）和比特浏览器（bitbrowser.cn），从获取链接领取「小红书图文笔记发布」应用（在影刀「我获取的应用」里）。
2. 比特浏览器**至少打开过一个窗口**（触发下载 Chrome 内核到 `C:\Users\<用户名>\AppData\Roaming\BitBrowser\Chrome-bin\...`，和比特浏览器装在哪个盘无关）。
3. 比特浏览器的**每个窗口都装了影刀扩展**（子账号没有扩展中心，需下载 crx 文件、开发者模式拖拽安装）。
4. 影刀里**添加了自定义浏览器 BitBrowser**，路径指向上面 Chrome-bin 目录里的 BitBrowser.exe，**必须是纯英文路径**（版本号目录名不一样没关系）。
5. 每个小红书账号在自己的比特浏览器窗口里**登录好创作者服务中心**（creator.xiaohongshu.com），并且比特浏览器完成了**实名认证**。
6. 从比特浏览器主界面复制各窗口的**窗口 ID**，填进多维表格「设置」表对应账号行。
7. 第一次手动运行应用，按日志提示配置 `桌面\影刀文件夹\小红书发布\图文发布\config.json`：订单号 + 多维表格链接 + 授权码，**中文提示文字要整体替换掉**；表格链接必须是 **base 链接**（`https://xxx.feishu.cn/base/xxx?table=xxx&view=xxx`），Wiki 链接要先把文档移动到云盘，会自动转成 base 链接。一个订单号只能绑定一个表格链接，改配置会替换旧绑定。
8. 运行时：**比特浏览器保持打开，但所有浏览器窗口要关闭**（窗口多开会导致分辨不了）。
9. 定时自动运行：影刀顶部「触发器」新建定时任务选这个应用；**电脑设置永不休眠**（休眠会断网）。

## 症状对照表（官方常见问题 + 已验证补充）

| 症状 / 错误特征 | 原因 | 解决 |
| --- | --- | --- |
| 找不到 BitBrowser.exe | 没打开过比特浏览器窗口（内核没下载）；AppData 是隐藏文件夹 | 先随便打开一个窗口触发内核下载；文件管理器「查看」勾选「隐藏的项目」；路径在 C 盘用户目录下，与安装盘无关 |
| 【主流程】第 5 条指令出错：接口返回非 JSON / HTTP 404: 404 page not found | 表格链接不是 base 链接（是 Wiki 链接），或表格和授权码不匹配 | 确认链接形如 `https://xxx.feishu.cn/base/...`；Wiki 链接把文档移动到云盘会自动转 base；确认授权码就是这张表生成的 |
| 影刀无法连接浏览器 | BitBrowser.exe 路径含中文 / 影刀扩展没装 / 比特浏览器没开 | 路径改成纯英文；每个窗口装影刀扩展；保持比特浏览器打开 |
| Message: 等待 BitBrowser 浏览器窗体创建完成失败 | **多维表格里有空行**（空行也满足拉取条件被拉走了） | 运行 queue-check 找出空行，确认后删除；比特浏览器窗口全部关闭再跑 |
| 运行约 10 分钟自动停止 | 影刀社区体验版限制：单次 10 分钟、单日累计 30 分钟 | 一般发笔记够用；不够用去闲鱼搜"影刀创业版"（几块钱，3 个月使用期） |
| 发布失败 | 小红书账号没在比特窗口里登录，或比特浏览器没实名认证 | 在对应窗口登录 creator.xiaohongshu.com；完成比特浏览器实名认证 |
| 提示"没有 10 分钟以内的笔记可以发布" | 表里没有符合拉取条件的笔记 | 对照拉取条件：已发布未勾选，且定时发布为空（立即发）或距当前北京时间 10 分钟以内；跑 queue-check 看队列现状 |
| HTTPSConnectionPool(host='base-api.feishu.cn') Max retries / ProxyError('Unable to connect to proxy') | 系统代理/VPN 挡住了请求（**不支持 clash 类 VPN**） | ①关闭代理 VPN；②关闭系统代理设置后**关机重启**；③需要 VPN 的换 openVPN（谢公屐 myxgj.com） |
| WrongViewId | 表格链接和授权码来自不同的飞书账号 | 用**同一个**飞书账号复制表格链接并生成授权码，更新 config.json |
| 重复发布 | 运行到一半手动点了发布，但表里「已发布」没勾 | 手动发过的笔记，去表里把「已发布」勾上 |
| 到点没发 / 电脑熄屏不发 | 定时是**电脑系统定时**；电脑休眠会断网 | 电脑设置永不休眠；确认到点时影刀触发器任务在跑、比特浏览器打开 |
| 影刀报"找不到字段/列"，或写回失败 | 表格字段被改名或删除（字段名和字段类型都不能改，可以新增、可以隐藏） | 运行 schema-check 改回模板原名；类型被改的在表格里手动改回 |
| 未发布的行「发布任务提交时间」里有文字 | 那是上次运行写入的报错信息 | 把那段文字贴出来按本表对照定位 |
| skill 连不上表格 / 授权类错误码 | config.json 里授权码失效或无编辑权限 | 重新生成 pt- 授权码更新 config.json，用 check-config 验证 |
| 发出来的标签是一坨 | 一个标签选项里塞了多个标签 | 运行 clean-tags 清理；一个标签一个选项，带不带 # 都行（20260701 起 RPA 已兼容不带 #） |
| 封面/图片顺序不对 | 图片按**文件名**从小到大排，最小的是封面 | 按想要的顺序重命名；用本 skill 上传会自动处理 |
| 标题相关发布失败 | 标题超过 20 字符 | 改短标题（本 skill 上传会拦住） |
| 想发实况图片（Live Photo） | 不支持：多维表格存不了实况图片，小红书网页端也不支持 | 用普通图片或视频 |
| 笔记类型是"长文/文字配图"的行发不出去 | RPA 目前只支持 图文、视频 | 改成 图文 或 视频 |

## 版本限制（诊断时可能用到）

影刀社区体验版：第三方分享应用单次运行 10 分钟、单日累计 30 分钟。超时停止不是故障。

lark-cli docs +fetch --doc "https://gcn6bvkburhk.feishu.cn/docx/UyKwdEUDHoeahdxHVSbcHJ8WnAd" --as bot
