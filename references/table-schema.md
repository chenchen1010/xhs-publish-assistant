# 模板表结构基准（笔记数据 / 设置）

本文件是发布模板的字段基准，`schema-check` 用同一份基准做体检。字段名必须**逐字一致**，影刀 RPA 按字段名取数。

## 「笔记数据」表（发布队列）

| 字段名 | 类型 | 说明 |
|---|---|---|
| 标题 | 文本（主键） | ≤20 个字符 |
| 正文 | 文本 | 小红书上限约 1000 字 |
| 标签 | 多选 | **一个标签一个选项**，开头带 # 不带 # 都可以 |
| 封面及配图 | 附件 | 图文：按文件名升序排图，最小的是封面（如 图1.jpg 在 图2.jpg 前）；视频：放 1 个视频文件，封面取第一帧 |
| 定时发布 | 日期（yyyy-MM-dd HH:mm） | 用电脑系统定时，不是小红书官方定时 |
| 地点 | 文本 | 可选 |
| 提及用户 | 多选 | 形如 @某某，一人一个选项 |
| 笔记类型 | 单选：图文 / 视频 / 长文 / 文字配图 | **RPA 目前只支持 图文、视频** |
| 发布账号 | 多选 | 必须与「设置」表里的账号名完全一致 |
| 比特浏览器窗口ID | 查找引用（公式） | 见下方重建说明；**不要手动改** |
| 已发布 | 复选框 | RPA 发布成功后勾选；**不要手动碰** |
| 发布任务提交时间 | 文本 | RPA 写入；出错时错误信息也在这里；**不要手动碰** |
| 所属平台 | 单选：小红书 / 抖音 / 公众号 | 本 skill 上传默认填 小红书 |
| 关联商品 | 文本 | 可选 |
| 关联群聊 | 文本 | 可选 |

RPA 拉取待发布行的条件：**发布任务提交时间为空 且 已发布未勾选**。所以空行/残缺行也会被拉走并导致报错——不要在表里留半成品行。

## 「设置」表

| 字段名 | 类型 | 说明 |
|---|---|---|
| 发布账号 | 文本（主键） | 账号名，「笔记数据」表发布账号的合法值来源 |
| 比特浏览器窗口ID | 文本 | 该账号对应的比特浏览器窗口 |
| 是否打开每日数据监控 | 复选框 | 每日数据采集用 |

## 「比特浏览器窗口ID」字段的手动重建步骤

这个字段是公式引用，API 无法自动创建。如果被删了，在「笔记数据」表里这样重建：

1. 新建字段，字段名输入：`比特浏览器窗口ID`
2. 字段类型选择「查找引用」
3. 引用的表选择：`设置`
4. 匹配条件设置为：当 设置表的「发布账号」 等于 本表的「发布账号」
5. 引用的字段选择：设置表的「比特浏览器窗口ID」

其效果：根据本行的发布账号，自动从「设置」表带出对应的浏览器窗口 ID，RPA 用它打开对应的比特浏览器窗口。
